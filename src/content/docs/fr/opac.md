Le catalogue public est sur la page de connexion, sans compte. La recherche accepte un texte libre, un type de document, et affiche vingt notices par page. La fiche d’un titre montre la disponibilité.

Les filtres proposés sur cet écran : tous les supports, livre, DVD, revue, bande dessinée.

La disponibilité publique indique le site et le nombre de réservations en attente. Elle ne donne ni le nom du lecteur qui a réservé, ni le détail « à rechercher » (regroupé avec « indisponible »). Les couvertures, lorsqu’un ISBN est connu, s’affichent sans compte.

Le même écran liste les événements publics à côté du catalogue. Les horaires et l’adresse viennent de la fiche bibliothèque, également publique.

![Page Mes emprunts, thème clair.](screen:opac-loans "Le lecteur voit ses prêts et leurs échéances.")

Un exemplaire en prêt montre la date de retour prévue, dans le fuseau de la bibliothèque, tant que l’échéance n’est pas dépassée. Les exemplaires perdus, manquants, en cours de désherbage ou sortis du fonds sont absents de cette liste.

## Une fois connecté

Le catalogue connecté reprend la recherche. Le lecteur ouvre ensuite :

- Mes emprunts, pour prolonger un prêt dans la fenêtre autorisée ;
- Mes réservations, pour suivre ou annuler les siennes ;
- Mon profil, pour le mot de passe, la langue, l’historique et les suggestions d’achat.

Poser une réservation depuis le catalogue exige un compte qui peut réserver au moins pour lui-même. Le personnel n’utilise pas cet écran pour le prêt : le guichet est [Prêts et retours](/fr/documentation/circulation/).
