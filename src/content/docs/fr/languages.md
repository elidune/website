Deux familles de langues coexistent. Elles ne se règlent pas au même endroit.

## Interface

L’interface est traduite en anglais, français, allemand et espagnol. Les quatre langues portent les mêmes libellés.

Sans session, la langue suit le navigateur. Avec une session, elle suit la langue enregistrée sur le compte, puis le choix mémorisé. Le sélecteur est dans la barre de l’application. Clair, sombre ou système est un réglage distinct, pas une langue.

À la première configuration, le compte administrateur choisit parmi ces quatre langues. Le profil la modifie ensuite.

## Notices et comptes

La langue d’une notice ou d’un lecteur utilise une liste plus longue : inconnue, français, anglais, allemand, espagnol, italien, portugais, japonais, chinois, russe, arabe, néerlandais, suédois, norvégien, danois, finnois, polonais, tchèque, hongrois, roumain, turc, coréen, latin, grec, croate, hindi, hébreu, persan, catalan, thaï, vietnamien, indonésien, malais.

Seules les quatre premières langues parlées ont une interface traduite. Les autres restent des valeurs de fiche.

## Modèles d’e-mail

L’onglet Modèles d’e-mails n’édite que le français et l’anglais. La langue affichée dans l’interface ne choisit pas, à elle seule, la langue d’un message.

**Avis au lecteur** : relances, réservation prête, réinitialisation de mot de passe. Ordre : langue du compte si elle est française, anglaise, allemande ou espagnole, puis langue de la bibliothèque, puis français, puis anglais. L’italien, « inconnue » et une valeur absente sont sautés. Ces modèles sont livrés dans les quatre langues.

**Autres messages** : code de second facteur, code de secours, annonce d’événement, prêt clos par un inventaire. Français puis anglais, ou anglais puis français. Toute autre langue, y compris l’allemand et l’espagnol, commence par le français. Ces modèles ne sont livrés qu’en français et en anglais.

Pour chaque langue, un texte déjà enregistré dans les paramètres est essayé d’abord, puis le texte livré avec le logiciel. La langue d’un compte neuf est le français, et elle peut rester vide.
