Cette page accueillera le parcours après l'installation. Le détail des écrans n'est pas décrit ici.

## Ce que le guide couvrira

- Ouvrir l'interface une fois les services démarrés.
- Créer le premier compte avec l'assistant.
- Repérer le guichet, le catalogue et les paramètres.

## Fait déjà écrit dans le dépôt du logiciel

Le README du logiciel indique qu'il n'existe pas de compte administrateur par défaut, et que l'assistant de l'interface conduit le premier lancement (`POST /api/v1/first_setup`).

La suite (ordre des écrans, champs demandés) sera rédigée à partir du logiciel, pas de mémoire.
