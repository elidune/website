Chaque domaine a sa page. Les procédures décrivent les écrans, pas le fonctionnement interne. Le détail technique est dans la [documentation développeur](/fr/dev/).

## Au guichet et dans les rayons

- [Catalogue](/fr/documentation/catalogue/) : notices, recherche Z39.50, import MARC.
- [Exemplaires](/fr/documentation/copies/) : code-barres, cote, disponibilité, notes.
- [Dépôts](/fr/documentation/deposits/) : documents reçus d’un autre établissement.
- [Inventaire](/fr/documentation/inventory/) : session, scan, clôture, consolidation.
- [Lecteurs](/fr/documentation/patrons/) : comptes, type de public, responsable légal, anonymisation.
- [Prêts et retours](/fr/documentation/circulation/) : guichet, forçage, exceptions, tablette.
- [Réservations](/fr/documentation/holds/) : file par notice, prélèvement, site de retrait.
- [Relances et amendes](/fr/documentation/reminders-fines/) : trois niveaux d’e-mail, paiement plafonné au reste dû.
- [Désherbage](/fr/documentation/weeding/) : candidat au retrait, sortie du fonds.

## Autour du catalogue

- [Acquisitions et suggestions](/fr/documentation/acquisitions/) : fournisseurs, budgets, commandes, suggestions.
- [OPAC](/fr/documentation/opac/) : catalogue public sans compte, et espace du lecteur.
- [Événements](/fr/documentation/events/) : annonces, audiences, consentement, désinscription.
- [Statistiques](/fr/documentation/statistics/) : catalogue, lecteurs, prêts, requête avancée.
- [Multi-sites](/fr/documentation/sites/) : lieux, retraits, transits.
- [Langues](/fr/documentation/languages/) : interface, langue du compte, langue des messages.

Les modules facultatifs (acquisitions, suggestions d’achat, désherbage, transits, dépôts, événements, inventaire, Z39.50, import MARC, statistiques, compteurs de fréquentation) se coupent dans Paramètres, onglet Modules. Le profil « essentiel » désactive acquisitions, suggestions d’achat, désherbage, transits, dépôts et compteurs de fréquentation, même si d’autres cases du même écran sont cochées. Événements, inventaire, Z39.50, import MARC et statistiques restent disponibles. Voir [Administration](/fr/documentation/administration/).
